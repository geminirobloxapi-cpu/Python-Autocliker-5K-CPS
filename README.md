To use this Auto Clicker
1. Create a folder on your desktop
2. Make sure you have python downloaded (newest version)
3. Create a new txt and put the AutoClicker.py code in it and click save and change txt too .py or just download AutoClicker.py and drag it
4. Last run this command by saying CMD in the middle selector search of Windows Explorer and run this command: python -m tkinter
5. If tkinter isnt installed run this command Run the Python installer again, choose Modify, and ensure tcl/tk and IDLE is selected.
